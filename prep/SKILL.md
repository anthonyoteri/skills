You turn a situation into a short, clear message with the PREP framework from Vinh Giang's [The PREP Framework: How To Communicate Confidently In Any Situation!](https://www.youtube.com/watch?v=2zvvQj9ezWg). A message with no structure waffles. PREP gives every thought one place to go: point, reason, example, point.

## 1. Settle the point

Needs no CLIs or other skills.

The situation is the skill's argument. Without one, ask "What situation should I explain?" and wait.

Settle the one **point** the message must carry: the answer, opinion, request or recommendation the audience should leave with. Use the audience and outcome the argument names. If the point is not clear from it, ask one question and wait.

Done when you can state the point in one sentence.

## 2. Gather the reason and example

The reason and the example must come from the user, never from you. Take them from the argument, or from the repo or files the argument points at when you can verify them there. Name where each fact came from. Do not invent facts, numbers or cases.

For each part the argument and sources do not supply, ask the user to provide it in one short question, and wait. For the reason: "Why should your audience care or agree, and what does it change for them?" For the example: "What is one real case, with details, that shows it?" Ask both in one message when both are missing.

When the facts you gather work against the point, say so and ask whether to change the point.

Done when the reason and the example each trace to the user or a source you checked.

## 3. Write it

- **Point**: the point, up front, in one sentence.
- **Reason**: why the audience should care or agree, in two to four sentences. Cover each benefit the user gave, and say what it changes for the audience in practice.
- **Example**: the gathered case that shows the reason is true, with real details (who, what, how much). Include the cost or the catch when the facts show one. A claim with no detail is not an example.
- **Point**: the point again, in fresh words, tied to the outcome you want and the next step you ask for.

Use plain words. Cut filler such as "alignment" and "synergy": a message that says nothing in many words fails PREP.

Done when each part is a short block, every benefit and fact the user gave is used, the closing point matches the opening point, and the message takes about a minute to say aloud.

## Reply

Reply with the four labeled parts (Point, Reason, Example, Point), then the whole message as one paragraph ready to say aloud. Add nothing else.
